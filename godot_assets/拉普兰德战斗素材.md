# 拉普兰德战斗素材

制作：内置 imagegen，以 `lappland_8dir_walk_4frames.png` 为角色和画风参考，透明背景。原始生成图保存为 `lappland_combat_source.png`，原图不覆盖。

`prepare_combat_atlas.py` 输出 `lappland_combat_64.png`（896×320，14列×5行，每格64×64）。**不按均匀网格切割**：生成图并非规则网格，剑会伸进相邻格；角色画得也比行走图小。脚本的做法：

1. 按 alpha 连通区域分离出每一帧（有一处两帧由剑尖相连，在最细的列处切开）。
2. 按同方向行走帧的身高统一缩放，每一行（方向）只用一个比例，不按帧单独缩放。测身高时忽略宽度不足 14 像素的行，以排除剑身；也不计举剑、深蹲、受击三类姿势。
3. 每帧的脚底和身体中线对齐到行走帧的对应位置。
4. 预乘 alpha 后用 BOX 降采样，再把 alpha 二值化，与 `lappland_8dir_walk_32.png` 的处理方式相同。

改用64格，是为了让剑不被截断。格子中心相对脚底的位置与32格的行走帧相同，billboard 不需要额外偏移。`test_lappland.gd` 逐方向检查攻击帧与待机帧：脚底线相差不超过 1.5 texel，身高比在 0.88–1.12 之间。

2026-09-29 修正：旧版做法是均匀网格加最近邻降采样，问题有三：攻击时角色缩到约80%、头顶下沉约5 texel；朝北攻击时脚底抬高约5 texel；多帧剑被截断。

**仍未解决（需要重新生成原图）**：西南行与南行几乎相同，没有画出斜侧身；北行14帧彼此差别很小，背面看不出挥剑。这是生成图的内容问题，切图脚本改不了。

行：南、西南、西、西北、北。东、东南、东北由对应西侧帧水平翻转。列：左斩3帧、逆斩3帧、时针扫影4帧、剑气斩3帧、受击1帧，共70帧。`lappland_animator_3d.gd` 创建 SpriteFrames，战斗12 FPS，行走仍8 FPS。

弧光、新月、碎屑、X闪光使用 `game/combat_vfx.gd` 的程序几何，在640×360视口直接栅格化，保留任意攻击方向与逐帧宽度收缩；没有另外生成约5张特效贴图集。黑边、亮芯分层，玩家效果不透明度最高0.7，预警材质优先级20。蓄力点、绕身线及剑身闪光由 `player_aura.gd` 生成像素贴图。
