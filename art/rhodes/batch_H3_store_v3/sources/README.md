# STORE v3 generated originals

These nine transparent PNGs are the image-generation originals. The local
`../build_store.py` makes native assets from each one by a uniform integer
reduction and Rhodes palette quantization. Its manifest records the factor,
source dimensions and SHA-256 for every asset.

Art direction: clean Rhodes Island base illustration translated to readable
pixel art; zero-yaw front-facing furniture with shallow horizontal top planes,
darker local outlines, three shaded tones and a highlight per material, warm retail lighting,
and no grime. Visual references were the accepted console v4, H2 hardware,
`closureRoom_2026` and `elite_2019`. Each original isolates one item on
transparent canvas: crowded self-service counter, weapon glass case,
equipment glass case, densely stocked product shelf, warm shop sign,
stacked merchandise boxes, pendant light, product poster or potted plant.

The two display cases, product shelf and stacked boxes were regenerated for v3 with
horizontal frame edges and vertical posts. The clean warm floor is a native
geometric module and contains no generated stains.

The STORE/B1-01 lettering, accepted logo marks and product/price UI were
polished on the native grid after reduction; the underlying furniture was
generated as images, not built from rectangles.
