# Generated originals

These transparent originals were generated individually with the built-in
image_gen tool. `prompts.json` preserves the complete final prompts and style
reference paths. Originals remain unmodified; the batch build reduces them
uniformly by integer factors, thresholds alpha and quantizes to the Rhodes palette.

- `engineering_drone_source.png`: zero-yaw hovering engineer, grey body, small cyan cameras.
- `construction_work_lamp_source.png`: level lamp head, vertical shaft and T-foot.
- `corridor_debris_source.png`: low front-facing crates, panels and disconnected cables.

The accepted L0 tarp and batch 1 v5 wall/door modules are reused separately by
hash. They were not regenerated. All geometry and lettering is drawn at native
scale; furniture/hardware source sections are never stretched independently.
