# ARMORY v4 generated originals

These seven transparent PNGs are the image-generation originals. The local
`../build_armory.py` uniformly reduces and palette-quantizes them; per-item
integer factors and SHA-256 hashes are in `../manifest.json`.

Art direction: accepted console v4 and H2 hardware construction, with the
light, clean `elite_2019` armory treatment. Regenerated pieces use the same
zero-yaw front-on projection: horizontal top/bottom, vertical supports and
only a shallow top strip. Each original isolates one shaded piece:
equipment workbench, recessed weapon wall, jointed robotic
arm, level overhead hoist, peg tool board, equipment case or task light. Local
dark seams distinguish white enamel from the light wall. The weapon
schematic screen, accepted S mark and light-room value polish were applied
only after uniform reduction to the native grid.

For v4, only the task lamp original changed: its diffuser and housing are
level, and its mount hangs vertically. The same light-enamel value polish
used by the other armory hardware is applied after reduction.
